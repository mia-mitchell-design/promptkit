## ⚙️ How To Use

This toolkit is designed to help you get **predictable**, **structured**, and **high-quality** outputs from large language models — no matter the task.

Below is a simple onboarding guide for getting the most out of each module.

### **1. Start With a Purpose**

Every prompt in this toolkit is built for a specific use case.

Before running a prompt, ask yourself:

✔️ *What do I want the model to do?*

✔️ *What constraints or structure do I need?*

✔️ *Is this a code task? Analysis? Writing? Exploration?*

Choosing the right module dramatically improves results.

### **2. Use Prompts as Templates — Not Scripts**

Each pattern is intentionally modular. You should:

- replace placeholders
- add constraints
- remove steps you don’t need
- combine modules when appropriate

You are meant to **shape** these prompts to your workflow.

### **3. Add Context (The Model Can’t Guess)**

LLMs do their best work when they have context.

When using any module:

Provide:

- file trees
- code snippets
- logs
- API responses
- business rules
- examples

The more grounding you give, the more accurate the result.

### **4. Use “Clarity Mode” to Improve Output Quality**

The **Clarity Mode** pattern is compatible with *every other prompt* in the toolkit.

To tighten output:

- add Clarity Mode before the module
- or wrap the module with its rules

This produces more consistent formatting.

### **5. Iterate Through Conversation**

Think in loops, not one-offs.

Good workflow:

1. Run the prompt
2. Evaluate the output
3. Refine the request
4. Add examples
5. Re-run

Iterative prompting is how you get production-quality results.

### **6. Chain Modules for More Complex Tasks**

You can combine modules like building blocks.

Examples:

- **Codebase Explorer** → **Architectural Breakdown** → **Executive Summary**
- **Precision Debugger** → **Code Rewrite Engine**
- **Persona Switcher (Senior Engineer)** → any prompt

You’re not limited to single modules; build workflows.

### **7. Use the Format Section Exactly as Written**

Most modules include:

- bullet structure
- headings
- steps
- constraints
- delivery format

These are part of the engineering — not decoration.

Following the format increases accuracy significantly.
