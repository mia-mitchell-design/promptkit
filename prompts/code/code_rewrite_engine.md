## Code Rewrite Engine

**What it solves**

Produces clean, modern, idiomatic rewrites of existing code.

**When to use it**

When refactoring, modernizing, or translating between languages.

---

### 📌Full Prompt

```diff
Rewrite the following code according to the criteria below.

Criteria:
- Improve clarity and readability.
- Remove unnecessary complexity.
- Use modern, idiomatic conventions.
- Preserve behavior exactly.
- Add brief inline comments only where needed.

Output:
- Rewritten Code
- Notes on Key Improvements
```

---

### **Why it works**

You’re giving the model extremely clear boundaries: clarity, behavior preservation, and modern syntax.
