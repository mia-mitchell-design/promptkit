## Architectural Breakdown

**What it solves**

Breaks complex systems into clean components for analysis or brainstorming.

**When to use it**

Whenever you're designing or analyzing a system.

---

### 📌 Full Prompt

```markdown
Break down the system described below into clear architectural components.

Requirements:
- Identify major components
- Clarify responsibilities of each component
- Show data flow or request flow
- List bottlenecks or failure points
- Provide 2–3 alternative architectures

Format:
1. High-Level Overview
2. Component Breakdown
3. Data/Request Flow
4. Bottlenecks & Risks
5. Alternatives
```

---

### **Why it works**

This mirrors how senior engineers structure design reviews — it forces the LLM to think modularly.
