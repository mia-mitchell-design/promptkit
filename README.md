# PromptKit
A structured, developer-first library of reusable LLM prompt patterns.

PromptKit is a technical toolkit designed to reduce uncertainty, eliminate guesswork, and help engineers, analysts, and technical writers produce consistent, predictable, and high-quality outputs with large language models.

This repository contains a curated collection of reusable prompt templates, patterns, and frameworks — each engineered with clarity, constraints, and structure in mind.

### ⭐️ Features
* Reusable prompt modules
* Code exploration tools
* Accurate debugging workflows
* System design and architecture prompts
* Structured writing and summarization patterns
* ML analysis + data reasoning tooling
* “First day on the job” onboarding prompts
* Consistent formatting for reproducible outputs

### 📚 Toolkit Structure
PromptKit is organized into six categories:
1. Foundations & Principles
2. Code Generation & Debugging
3. Machine Learning & Data Analysis
4. Writing & Documentation
5. Structural Thinking
6. System Design & Architecture
   
Each category contains independent modules you can use individually or chain together for more complex workflows.

### 🚀 Get Going:

**Clarity Mode**
```
You are now in **Clarity Mode**.

Rules:
1. Use concise, plain language.
2. Structure your answer with clear headings.
3. Avoid filler or metaphors.
4. Prioritize correctness over creativity.
5. Explain reasoning only when asked.

Format:
- Summary
- Key Points
- Recommended Action
```

**Precision Debugger**
```
Activate **Precision Debugger Mode**.

Steps:
1. Identify the exact root cause.
2. Explain why it happens in 1–3 sentences.
3. Provide a minimal fix.
4. List potential side effects.

Format:
- Root Cause
- Why It Happens
- Minimal Fix
- Side Effects
```

**Codebase Explorer**
```
You are assisting me in exploring an unfamiliar codebase.

Analyze the files or structure I provide and deliver:
- Project Summary
- Architecture Overview
- Important Modules
- Data/Request Flow
- Complexity Hotspots
- Suggested Starting Points
- Questions to Ask the Team
```

### 🧱 Philosophy
PromptKit is built on four guiding principles:
1. **Clarity over cleverness** — always reduce ambiguity.
2. **Structure is a feature** — predictable formats → predictable outputs.
3. **Constraints improve accuracy** — bounded tasks outperform vague ones.
4. **Prompts are tools, not magic** — modular, reusable, explainable.
